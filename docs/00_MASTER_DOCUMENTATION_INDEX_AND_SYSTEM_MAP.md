## 🛠️ Tooling & Utility Scripts

All UnrealScript and package utilities are consolidated under the [`tools/`](file:///d:/Projects/unrealagentharness/tools/) directory:

| Script | Type | Description |
| :--- | :--- | :--- |
| [`Compile-UnrealScript.ps1`](file:///d:/Projects/unrealagentharness/tools/Compile-UnrealScript.ps1) | PowerShell | Automated `UCC.exe make` compiler with automatic safety backups. |
| [`Extract-UnrealScript.ps1`](file:///d:/Projects/unrealagentharness/tools/Extract-UnrealScript.ps1) | PowerShell | Automated `UCC.exe batchexport` tool to unpack `.uc` source trees from binary `.u` packages. |
| [`Extract_All_Scripts.bat`](file:///d:/Projects/unrealagentharness/tools/Extract_All_Scripts.bat) | Batch | One-click batch wrapper to decompile all base engine and mod scripts. |
