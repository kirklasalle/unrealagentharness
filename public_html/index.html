🛠️ Quick Start

Get Started in 3 Simple Steps

Zero bloat, zero heavy frameworks. Runs on standard Python 3.10+ on Windows 10/11 with zero Chromium overhead.

1️⃣

Clone Repository

Clone the open-source repository directly to your workspace or Unreal directory:

BASH
git clone https://github.com/kirklasalle/unrealagentharness.git
cd unrealagentharness
2️⃣

Install Dependencies

Install the lightweight Python requirements (standard Win32, FastAPI, and LLM drivers):

CMD / POWERSHELL
pip install -r requirements.txt
3️⃣

Launch Dedicated Cockpit

Start the standalone Win32 agent cockpit for your target game engine:

CMD
:: Universal Engine Selector
launch_harness_universal.bat

:: UT99 GOTY / OldUnreal 469e
launch_harness_ut99_goty.bat

:: Unreal Tournament 2004
launch_harness_ut2004.bat
